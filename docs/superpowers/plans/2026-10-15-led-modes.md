# LED Modes, Lamp & Schedule Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the LED Strip on/off toggle with a four-way LED mode (On · Auto · Lamp · Off), add a lamp colour with live preview and a daily on/off schedule, and keep the Pi's clock and timezone in step with the browser.

**Architecture:** A new pure module `raceflag/led_modes.py` holds every decision rule (mode table, schedule window, colour scaling, config fallbacks). A new `raceflag/clock.py` computes local time with `zoneinfo` and applies browser time sync. `LEDController` asks `decide_output()` once per tick and either fills a solid colour, goes dark, or runs the existing flag/timed/idle-chase logic unchanged. The web server gains six routes; the frontend gains a mode pill and two popups.

**Tech Stack:** Python 3.11+ (Pi OS), FastAPI <0.100 with pydantic v1, `zoneinfo` + `tzdata`, pytest / pytest-mock, vanilla JS/CSS frontend.

**Spec:** `docs/superpowers/specs/2026-10-14-led-modes-design.md` (Pi design) and `../raceflag_specs/features/014-led-modes.md` (shared behaviour spec). Read both before starting.

- Modes: exactly `"on"`, `"auto"`, `"lamp"`, `"off"`. The mode always starts as `"on"` at boot and is **never** persisted.
- New `config.json` keys and defaults: `schedule_on "08:00"`, `schedule_off "23:00"`, `lamp_color "#FFFFFF"`, `lamp_brightness 100`, `timezone ""`.
- Schedule window is half-open `[on, off)` in local minutes; `off < on` crosses midnight; `on == off` is rejected (HTTP 422, and Save disabled in the UI).
- Times are 24 h `HH:MM` strings (`00:00`–`23:59`, two-digit hour).
- Lamp colour is `#RRGGBB`, stored upper-case. Lamp brightness is an integer 0–100. Pixel value per channel = `(channel * brightness + 50) // 100` (round half up), before the hardware cap `led_brightness`.
- Lamp swatches: Red `#FF0000`, Yellow `#FFD700`, Green `#00FF00`, White `#FFFFFF`, plus Custom (native colour picker). No warm-white preset.
- Lamp preview expires **60 s** after its last update. The UI throttles preview requests to one per **150 ms**.
- Time sync sets the system clock only when it is more than **60 s** off, using `date -u -s @<epoch>`. The system timezone is never changed. Unknown timezone → 422. An `epoch_ms` before 2025-01-01 (`1735689600000`) → 422.
- "Session live" = `state.session.is_active or state.replay_mode`.
- Hotspot animation shows in every mode, including Off. Test effects show in On, Auto and Lamp, and stay dark in Off.

## Review Focus

1. **Hand-edited or corrupt `config.json` values** (bad `HH:MM`, equal on/off times, `lamp_color: "green"`, `lamp_brightness: 300`, unknown timezone): the unit must still boot, using the defaults for the bad values. Pinned by `test_schedule_from_config_*` / `test_lamp_from_config_*` (Task 3) and `test_local_minutes_unknown_timezone_falls_back_to_utc` (Task 1).
2. **Daylight-saving changes**: an owner in a DST timezone expects the schedule to follow the wall clock all year. Pinned by `test_local_minutes_follows_dst` (Task 1).
3. **A phone with a reset or badly wrong clock** (e.g. year 2001) opens the page: the Pi's clock must not be dragged backwards. Pinned by `test_sync_rejects_implausible_epoch` (Task 1) and `test_time_sync_rejects_implausible_epoch` (Task 2).
4. **Switching from Off back to Lamp or On mid-session**: the current flag animation shows immediately, not the lamp colour or chase. Pinned by `test_switching_off_to_lamp_mid_session_shows_current_flag` (Task 4).
5. **A session ending inside Auto's off window**: the chequered flag plays its full time, then the strip goes dark, not back to the chase. Pinned by `test_auto_session_end_in_off_window_plays_checkered_then_dark` (Task 4).

```python
"""Local time for the LED schedule, and clock/timezone sync from the browser.

The system timezone is never changed: overlayroot would discard it at reboot. RaceFlag
stores the browser's IANA timezone in config.json and computes local time itself.
"""
from __future__ import annotations

import logging
import subprocess
import time
from datetime import datetime, timezone, tzinfo
from pathlib import Path
from typing import Callable
from zoneinfo import ZoneInfo, ZoneInfoNotFoundError

from raceflag.config import Config, save as save_config

logger = logging.getLogger(__name__)

CLOCK_TOLERANCE_S = 60
MIN_EPOCH_MS = 1_735_689_600_000  # 2025-01-01T00:00:00Z — older browser clocks are wrong


def _zone(tz_name: str) -> tzinfo | None:
    """Return the ZoneInfo for tz_name, or None if it is empty or unknown."""
    if not tz_name:
        return None
    try:
        return ZoneInfo(tz_name)
    except (ZoneInfoNotFoundError, ValueError, OSError):
        return None


def local_minutes(tz_name: str, now: datetime | None = None) -> int:
    """Minutes since local midnight in tz_name. UTC when tz_name is empty or unknown."""
    now = now or datetime.now(timezone.utc)
    local = now.astimezone(_zone(tz_name) or timezone.utc)
    return local.hour * 60 + local.minute


def _set_system_clock(epoch_s: float) -> None:
    subprocess.run(
        ["date", "-u", "-s", f"@{int(epoch_s)}"],
        check=False, capture_output=True, timeout=5,
    )


def sync(
    tz_name: str,
    epoch_ms: int,
    cfg: Config,
    cfg_path: Path | None,
    set_clock: Callable[[float], None] | None = None,
    now: Callable[[], float] = time.time,
) -> dict:
    """Store the browser's timezone and correct the clock if it is more than 60 s off.

    Raises ValueError for an unknown timezone or an implausibly old epoch.
    """
    if _zone(tz_name) is None:
        raise ValueError(f"Unknown timezone: {tz_name!r}")
    if epoch_ms < MIN_EPOCH_MS:
        raise ValueError("epoch_ms is before 2025-01-01; the browser clock looks wrong")

    if tz_name != cfg.timezone:
        cfg.timezone = tz_name
        if cfg_path:
            save_config(cfg, cfg_path)
        logger.info("Timezone set to %s", tz_name)

    epoch_s = epoch_ms / 1000
    adjusted = abs(now() - epoch_s) > CLOCK_TOLERANCE_S
    if adjusted:
        logger.info("System clock off by %.0f s — setting from browser", now() - epoch_s)
        (set_clock or _set_system_clock)(epoch_s)
    return {"timezone": tz_name, "clock_adjusted": adjusted}
```

```python
"""LED mode rules (feature 014). Pure functions — no I/O, no clocks."""
from __future__ import annotations

import re

MODES: tuple[str, ...] = ("on", "auto", "lamp", "off")

DEFAULT_SCHEDULE: tuple[int, int] = (8 * 60, 23 * 60)
DEFAULT_LAMP: tuple[str, int] = ("#FFFFFF", 100)

_HHMM = re.compile(r"([01]\d|2[0-3]):([0-5]\d)")
_HEX = re.compile(r"#[0-9A-Fa-f]{6}")


def in_window(now_min: int, on_min: int, off_min: int) -> bool:
    """True if now_min is inside the half-open window [on, off). off < on crosses midnight."""
    if on_min < off_min:
        return on_min <= now_min < off_min
    return now_min >= on_min or now_min < off_min


def decide_output(mode: str, session_live: bool, effect_active: bool,
                  scheduled_on: bool, preview_active: bool) -> str:
    """What the strip shows this tick.

    "normal" = existing flag / timed-effect / idle-chase logic, "lamp_preview" = draft lamp
    colour, "lamp" = saved lamp colour, "dark" = all off. Hotspot is handled by the caller.
    """
    if mode == "off":
        return "dark"
    if session_live or effect_active:
        return "normal"
    if preview_active:
        return "lamp_preview"
    if mode == "on":
        return "normal"
    if mode == "auto":
        return "normal" if scheduled_on else "dark"
    return "lamp"


def parse_hhmm(value) -> int:
    """"21:30" -> 1290. Raises ValueError unless value is a 24 h HH:MM string."""
    m = _HHMM.fullmatch(value) if isinstance(value, str) else None
    if not m:
        raise ValueError(f"Invalid time {value!r}; expected HH:MM (24 h)")
    return int(m.group(1)) * 60 + int(m.group(2))


def is_hex_color(value) -> bool:
    return isinstance(value, str) and _HEX.fullmatch(value) is not None


def scale_rgb(hex_color: str, brightness: int) -> tuple[int, int, int]:
    """Scale #RRGGBB by brightness 0–100, rounding half up."""
    h = hex_color.lstrip("#")
    return tuple((int(h[i:i + 2], 16) * brightness + 50) // 100 for i in (0, 2, 4))


def schedule_from_config(on, off) -> tuple[int, int]:
    """Stored schedule as minutes; DEFAULT_SCHEDULE if either time is invalid or they match."""
    try:
        on_min, off_min = parse_hhmm(on), parse_hhmm(off)
    except ValueError:
        return DEFAULT_SCHEDULE
    return DEFAULT_SCHEDULE if on_min == off_min else (on_min, off_min)


def lamp_from_config(color, brightness) -> tuple[str, int]:
    """Stored lamp settings, each field falling back to its default if invalid."""
    color = color.upper() if is_hex_color(color) else DEFAULT_LAMP[0]
    valid = isinstance(brightness, int) and not isinstance(brightness, bool) and 0 <= brightness <= 100
    return color, brightness if valid else DEFAULT_LAMP[1]
```

```python
            if self._timed_effect == "race_start":
                self._step_race_start_animation()
            elif self._timed_effect == "checkered":
                self._step_checkered_animation()
            else:
                self._step_track_clear_animation()
        elif self._active_animation:
            if self._active_animation == "red_flag":
                self._step_red_flag_animation()
            elif self._active_animation == "yellow_flag":
                self._step_yellow_flag_animation()
            elif self._active_animation == "safety_car":
                self._step_safety_car_animation()
            elif self._active_animation == "virtual_sc":
                self._step_virtual_sc_animation()
        elif self._idle_active:
            self._step_idle_animation()

    def _tick(self) -> None:
        """Render one frame."""
        self._maybe_reload_effects()
        self._drain_queue()
        if self._active_animation == "hotspot":
            self._step_hotspot_animation()
            return
        output = self._decide_output()
        if output == "dark":
            self._fill(0, 0, 0)
        elif output == "lamp_preview":
            # The preview may end on another thread between decide and here.
            self._fill(*scale_rgb(*(self._preview or self._lamp)))
        elif output == "lamp":
            self._fill(*scale_rgb(*self._lamp))
        else:
            self._render_flag_or_idle()

    def _run(self) -> None:
        while not self._stop_event.is_set():
            self._tick()
            time.sleep(0.05)
```

```js
function _sendPreview(immediate) {
  // Trailing throttle: at most one request per PREVIEW_THROTTLE_MS, always the latest draft.
  if (!_lampDraft) return;
  const wait = immediate ? 0 : Math.max(0, PREVIEW_THROTTLE_MS - (Date.now() - _previewLastSent));

      body: JSON.stringify({ color: _lampDraft.color, brightness: _lampDraft.brightness }),
    }).catch(() => {});
```
